OpenPdfEditは、プライバシーを重視したPDFエディタ・ビューアで、すべての処理がお使いの端末内で完結します。PDFiumとWebAssemblyにコンパイルされたRustを採用しており、ファイルが外部サーバーに送信されることはありません。

主な機能

• PDFの閲覧と注釈追加
• テキストの編集と移動
• 画像の位置変更
• フォーム入力と署名の追加
• 機密情報の完全な墨消し
• ページの結合・分割・並べ替え
• パスワード保護とPDFの圧縮
• 書類の比較
• Markdownまたはプレーンテキストへのエクスポート
• 変更の取り消しとやり直し

すべてのコア機能は無料でアカウント登録も不要です。透かし追加はオプションのSupporter機能で、買い切り型の一回払いで利用可能になります（サブスクリプション、期間制限、利用回数制限なし）。

Chrome 103以降が必要です。

Windows および macOS 向けのデスクトップ版もあります。

GitHub: https://github.com/open-pdf-edit/OpenPdfEdit/
