OpenPdfEdit محرر وقارئ PDF يركّز على الخصوصية ويعمل بالكامل على جهازك - مدعوم بـ PDFium وRust المُصرَّف إلى WebAssembly، فملفاتك لا تغادر المتصفح أبدًا.

الميزات

• قراءة ملفات PDF وإضافة تعليقات
• تحرير النص وتحريكه
• تغيير موضع الصور
• تعبئة النماذج وإضافة التوقيعات
• إخفاء المحتوى الحساس بشكل نهائي
• دمج الصفحات وتقسيمها وإعادة ترتيبها
• حماية ملفات PDF بكلمة مرور وضغطها
• مقارنة المستندات
• التصدير إلى Markdown أو نص عادي
• التراجع عن التغييرات وإعادتها

جميع الميزات الأساسية مجانية ولا تتطلب حسابًا. العلامة المائية أداة Supporter اختيارية، تُفتح بدفعة واحدة - بدون اشتراك أو حدود زمنية أو حدود استخدام.

يتطلب Chrome إصدار 103 أو أحدث.

تتوفر إصدارات لسطح المكتب لأنظمة Windows وmacOS.

GitHub: https://github.com/open-pdf-edit/OpenPdfEdit/
