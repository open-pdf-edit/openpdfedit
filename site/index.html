The same editor, inside Chrome

The identical interface, compiled to WebAssembly with the PDF engine included — 5 MB installed. It runs entirely inside the browser sandbox: open a file, edit, save back to disk. No server round-trips, ever.

Local. Rendering, editing, and saving all happen on your machine. The only optional network call is signing in to an OpenApps account — and you never have to.

Careful. Saves are incremental: edits are appended, the original bytes are preserved, and existing digital signatures survive an annotation.

Open. The whole editor — engine, document model, and interface — is open source under MIT or Apache-2.0. Read it, build it, extend it.
